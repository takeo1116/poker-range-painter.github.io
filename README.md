# POKER RANGE PAINTER

テキサスホールデムのレンジ絞り込み練習用Webアプリ

## 機能

- 13×13のレンジ表を Value / Bluff / Exclude で塗り分け
- コンボ単位でValue／Bluffが共存。スート条件は「今回塗る対象」として指定
- 条件に一致／一致しないコンボだけ上書きし、対象外は維持
- 「コンボ編集」でセルをクリックして内訳を固定し、個別編集（右クリックで消去）
- 「塗る」では内訳はホバーに追従する閲覧専用表示
- 広い画面ではHero / Villainを並列表示、狭い画面ではプレイヤー切替
- Pre / Flop / Turn / River の4ストリート切替
- クリック＋ドラッグで上書き塗り（高速移動の補完・プレビュー対応）
- 右クリック／右ドラッグで一時的に消去（選択中の色・Flagは維持）
- 矩形指定（ツール切替またはShift＋ドラッグ）、Escで操作をキャンセル
- Undo/Redo（Ctrl+Z / Ctrl+Y）
- コンボ数ベースでリアルタイム集計

## 部分塗りの例

「塗る対象：条件に一致」で♠♠をValue、その後♥♥をBluffで同じAKsに塗ると、両方の分類が共存します。Excludeも選択条件の部分だけを消します。右ドラッグは条件に関係なくセル全体を消します。ボードと重複するコンボは集計から外れますが、分類は保持されます。

テストは `npm test` で実行できます。

## 参照レンジ（JSON）

参照レンジは補助表示用の名前付きプリセットです。ポジションやストリートは必須項目ではありません。
1レンジにつき1ファイルを src/data/reference-ranges/ に配置します。TSへの追記は不要です。
一覧はファイル名順になります。既存のBTN OpenとBB Call vs BTNのハンド内容は維持しています。

例（説明用のハンド）：

```json
{
  "id": "sb-vs-utg",
  "name": "SB vs UTG",
  "groups": {
    "call": ["JJ", "AQs"],
    "raise": ["AA", "KK", "AQs"]
  }
}
```

- ファイル名は id と一致させます（上の例では sb-vs-utg.json）。
- call は緑、raise はオレンジの枠で表示します。凡例は表示しません。
- 両方に含めたハンドは二重枠になります。頻度の数値は持ちません。
- Openは raise のみ、Callのみのレンジは call のみでも構いません。
- 参照枠は塗り状態・集計・Undo/Redoに影響しません。
- 同一グループ内の重複、不正なハンド表記、ID重複、ファイル名不一致などは検証エラーになります。

### ローカル専用の作成画面

```powershell
npm.cmd run dev
```

起動後に以下を直接開きます（ポート番号は開発サーバーの表示に合わせてください）。

http://localhost:5173/poker-range-painter.github.io/range-editor

通常の練習画面にはリンクを設けていません。作成画面は開発時のみ有効で、
npm run build の成果物やGitHub Pagesには含まれません。npm run preview でも利用できません。

1. 新規作成、既存レンジの読込、またはJSONファイルの読込を選ぶ。
2. 名前とIDを入力する。
3. Call／Raiseと操作を選び、ドラッグまたは矩形で入力する。
4. 「JSONを書き出す」でダウンロードする。
5. ファイルを src/data/reference-ranges/ へ配置する。既存レンジの更新時は同名ファイルを置き換える。
6. 以下で検証し、確認後にcommit・pushして公開へ反映する。

```powershell
npm.cmd run validate:ranges
npm.cmd test
npm.cmd run build
```

作成画面はファイルを直接リポジトリへ保存しません。JSONを配置するまでは通常画面の一覧も更新されません。
検証は本番ビルド時にも実行されます。本番ビルドには開発用エディターの混入チェックも含みます。

### 作成画面の操作

- 左ドラッグ：選択したグループへ追加、選択グループから消去、または両方から消去。
- 右ドラッグ：選択したグループだけ消去。他方のグループは維持。
- Shift＋ドラッグ／矩形ボタン：矩形選択。Esc：未確定の操作をキャンセル。
- Callの上からRaiseを塗ってもCallは残ります。
- Undo／Redo（Ctrl+Z／Ctrl+Y、Cmd+Z／Cmd+Shift+Z）：ドラッグ1回単位で操作を戻せます。読込・新規作成も戻せます。
- 入力欄では通常のテキスト編集のUndoを使用します。
- 下書き1件は同じブラウザ・同じURLのオリジンのlocalStorageへ自動保存します。IDや名前が未完成でも復元できます。
- ブラウザデータの削除や別ブラウザへの移動に備え、区切りごとにJSONを書き出してください。

参照レンジ選択欄の横にある緑・オレンジのボタンで、それぞれの枠を個別に表示／非表示にできます（表示だけを切り替えます）。コンボ内訳のカードは、♠黒・♥赤・♦青・♣緑で表示します。

## Preflop Trainer

通常URLの末尾に `#/trainer` を付けるか、ヘッダーの「Preflop Trainer」から開きます。GitHub Pagesでも直接アクセス・再読み込みできます。

ページを開くとすぐに出題します。Fold / Call / Raise はボタンまたは `←` / `↓` / `→`、回答後の次問は「次へ」または `Space`。回答後に登録レンジ全体と出題ハンドの位置を表示します。CallとRaiseの重複はどちらも正解、両方に未登録のハンドはFoldです。頻度は扱いません。

出題設定でレンジとハンドをいつでも変更できます。ハンドは169分類から等確率、スートは該当コンボからランダムに選びます。成績や終了区切りはなく、同じ問題が再び出ることもあります。設定のみLocal Storage（`range-painter.trainer.settings.v1`）に保存します。端末間の同期はありません。スマホでは出題設定を開閉できます。

Trainerの効果音は `src/trainer/audio/correct.mp3`（正解）と `wrong.mp3`（不正解）です。出題設定で効果音のON/OFF、音量、試聴を操作できます。初期音量は50%で、音の設定はLocal Storage（`range-painter.trainer.sound.v1`）に保存します。次問・出題設定変更・画面移動では再生を停止します。

Trainerのテーブル図は各レンジの任意項目 `scenario` で指定します。例：`{"tableSize":6,"hero":"BB","opener":"SB","stackBb":100,"stakes":"NL50","openSizeBb":2.5}`。`opener` を省略すると自分まで未オープン、指定すると単独Openへの対応を表します。コール済みや3Bet後の状況は対象外です。自分の席を手前に固定し、Fold済みと未アクションを区別します。`stackBb` は開始スタック、`openSizeBb` はレイズ後の合計bb数（未オープンの場合は想定Openサイズ）です。条件・サイズは任意で、未登録なら表示しません。既存20レンジは6max・100bb・NL50、Openサイズは未登録です。参照レンジ作成画面の「状況図」で編集でき、情報のないレンジは従来どおり名前だけ表示します。
